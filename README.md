# Atividade 1 - Repositório Git/GitHub

Projeto desenvolvido para a Atividade 1 da disciplina, com o objetivo de praticar o versionamento de código com Git e a publicação de um repositório no GitHub.

## Sobre o projeto

Um site simples em HTML, CSS e JavaScript que apresenta uma página de estudante, com imagens, estilos e uma pequena interação em JS.

## Estrutura do repositório
.
├── index.html      # Página principal
├── sobre.html       # Página "Sobre"
├── style.css        # Estilos do site
├── script.js         # Interatividade da página
├── erro.txt          # Registro de um erro encontrado durante o desenvolvimento e como foi resolvido
├── img/              # Imagens utilizadas no site
│   ├── logo.png
│   ├── banner.png
│   └── icon.png
└── .gitignore
```

## Como visualizar

Basta abrir o arquivo `index.html` em qualquer navegador.

## Histórico de commits

O repositório foi construído em pequenas etapas (mais de 15 commits), incluindo criação, edição e remoção de arquivos, para demonstrar o uso do controle de versão.
